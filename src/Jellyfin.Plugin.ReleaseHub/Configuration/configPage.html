ReleaseHub

Unified TV series and anime release calendar. ReleaseHub only ever reads your libraries — it never renames, moves, deletes or downloads media, and never edits Jellyfin metadata.

Matches awaiting confirmation

These library series could not be matched to a provider with enough confidence, so ReleaseHub deliberately leaves them out of the calendar rather than risk showing the wrong show's episodes. Confirm a match to include it. A confirmed match is never overwritten by an automatic one.

Synchronization

A hard ceiling on outbound provider calls per run, on top of the per-provider rate limiter.

Images

Images already held by Jellyfin are reused directly; only provider images for items outside your library are cached, and never written into your media folders.

Debug

API keys are redacted from every log line regardless of this setting.
