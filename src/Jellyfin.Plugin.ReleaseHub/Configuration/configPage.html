ReleaseHub

Unified TV series and anime release calendar. ReleaseHub only ever reads your libraries — it never renames, moves, deletes or downloads media, and never edits Jellyfin metadata.

Status

Matches awaiting confirmation

These library series could not be matched to a provider with enough confidence, so ReleaseHub deliberately leaves them out of the calendar rather than risk showing the wrong show's episodes. Confirm a match to include it. A confirmed match is never overwritten by an automatic one.

Providers

TVMaze
Default: https://api.tvmaze.com — TVMaze needs no API key for public use. This field exists only so the endpoint can be changed if TVMaze ever relocates it.
Checks that TVMaze answers at the address above. There is no key to verify here, so this tests reachability — a typo in the base URL, or an outbound connection being blocked.
AnimeSchedule
Default: https://animeschedule.net/api/v3
Create one from an Application in your animeschedule.net account settings, under the API tab. It is stored on the server and is never exposed to non-administrator users. Clearing this field and saving removes the key.
Tests whatever the field currently holds, so a key can be checked before it is saved.
TMDb (films)
Owning one film of a saga surfaces that saga's unreleased entries. This is the only place ReleaseHub looks beyond the exact items in your library.
Default: https://api.themoviedb.org/3
Default: https://image.tmdb.org/t/p/w500 — TMDb returns bare image paths, and the size segment at the end of this URL decides the resolution ReleaseHub requests.
This is the API Read Access Token from your themoviedb.org account's API settings — the long v4 token, not the shorter v3 key. Stored on the server and never exposed to non-administrator users.

Synchronization

A hard ceiling on outbound provider calls per run, on top of the per-provider rate limiter.

Images

Images already held by Jellyfin are reused directly; only provider images for items outside your library are cached, and never written into your media folders.

Debug

API keys are redacted from every log line regardless of this setting.
