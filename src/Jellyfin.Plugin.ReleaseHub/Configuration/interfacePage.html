Abyss spotlight

The Abyss theme installs by writing into jellyfin-web on disk. Among other things it adds a script tag to index.html that mounts its own hero carousel — an iframe — at the top of the home tab:

<script src="ui/spotlight-loader.js" data-abyss-spotlight></script>

On a server that also runs the Media Bar plugin, the two carousels are mounted in the same place and stack. The one underneath shows through as ghost text, a stray info button and a second row of pagination dots, cycling on its own schedule.

Because that tag lives in a file rather than in a plugin, uninstalling plugins never removes it, and editing the file by hand is undone by the next theme or server update. ReleaseHub strips it from the response instead, which no update can reverse. Everything Abyss installed stays on disk untouched: clearing this box brings the carousel back immediately.
